# UI fonts

The application bundles these variable fonts and loads them locally without a runtime CDN.

- Noto Sans SC: Chinese UI, Regular 400 / Medium 500 / Bold 700. The full variable face was copied from the matching locally installed `NotoSansSC-VF.ttf`. Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Inter: numeric metrics, Semi Bold 600. Upstream: https://github.com/google/fonts/tree/main/ofl/inter

Both fonts use the SIL Open Font License 1.1. The original license notices are retained in `NotoSansSC-OFL.txt` and `Inter-OFL.txt`. The font files are unmodified; the full Chinese character coverage is retained for player and team names.

Approved typography and semantic roles: `docs/modular-rewrite/R12-frontend-foundation-ui-system/approved-design-tokens-20261028.json`.
