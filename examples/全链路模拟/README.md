# 全链路模拟数据

本目录中的工作簿用于验证球队与球员导入、比赛与阵容导入、自动模型路由、正式推演、赛后复盘、能力候选和 AI 分析包。

## 文件

1. `01_球队球员模拟导入.xlsx`：4 支模拟球队、72 名球员及其位置、效力时间线、能力观察和可用状态。
2. `02_比赛阵容模拟导入.xlsx`：3 场模拟比赛、预计/确认阵容和动态标签。
3. `03_全链路操作清单.xlsx`：逐步验收项目和预期结果。

## 操作顺序

1. 打开“资源” → “球员中心” → “球员工作包” → 导入 `01_球队球员模拟导入.xlsx`，选择“新增并更新”，先预检，再确认写入。
2. 打开“比赛” → “比赛中心” → “数据链检查” → 导入 `02_比赛阵容模拟导入.xlsx`，先预检，再确认写入。
3. 打开“比赛” → “赛事推演”，直接按球队和开球时间选择比赛。客户端不会要求输入比赛编号。
4. 点击“查看模型判定”，确认赛事、规则包、模型版本和参数版本。
5. 选择 T-N（不限时间）、T-24h、T-6h 或 T-1h，点击“开始正式推演”。
6. 比赛结束后进入“赛后复盘”，录入赛果和球员评分，生成兑现率、配合度、替补影响和能力更新候选。
7. 在“分析” → “分析与校准”运行完整分析，导出 AI 分析包，或生成单模块函数曲线候选。

规则包和模型包不会因导入这些工作簿而自动修改；所有能力与参数变化均先进入候选审核区。

## Windows 实机验收

根目录 `验收平台.bat` 会在完成自动构建后启动 release 客户端，并按上述顺序检查本次运行日志中的完整操作链。正式通过要求成功执行一次正式 P4；仅影子推演不会被当作完整发布验收。
