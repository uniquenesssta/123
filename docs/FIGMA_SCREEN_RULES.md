## 5. 层级与绑定

赛事 → 赛季 → 阶段 → 轮次依赖明确父ID。示例原为C1/S1/G1；切到C2后不沿用原赛季与阶段。Parent Changed场景允许为C2创建新赛季，但阶段与轮次保持禁用；其确认文本不再引用C1。

创建赛季、阶段和轮次相互独立：填完一个表单不代表已创建成功。保存中禁止重复提交，结果未确认保留草稿、先核验，不自动重发。

本场覆盖、阶段、赛季、具体赛事、赛事类型默认按范围优先；同范围再比较priority。代表性绑定确认明确C1/S1/G1、RP-A 1.2.0与顺序100。赛事或可用P4包缺失、父级变化、提交中、结果不明时，保存均禁用。
