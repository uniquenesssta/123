## 4. 请求、报告与历史

请求窗口必须为1–365天整数；预算可留空，否则必须为有限非负数。空预算不等于0；留空允许运行，但成本项可能警告。后端窗口clamp与前端提交校验分别记录，不声称任意输入控制器已实现。

默认请求为性能/成本30天、预算均空、操作人空；显式预算示例为单日2.00 USD、30日周期20.00 USD。两个最终确认各自核对对应参数，均不执行请求。

运行中禁止重复提交，无虚构百分比、报告哈希或完成时间，也没有假取消API。运行中保留A时明确标为上次报告，不当作本轮结果。结果未确认时先按请求时间、窗口、操作人与报告身份核验历史，不自动重发；新UUID不等于自动幂等。

历史只读，没有覆盖、编辑或删除入口。刷新不是重新验收，不重算旧报告。历史为空、读取中、读取失败、保留旧列表刷新及刷新失败分别显示。切换B的读取中/失败不显示A的证据；“B读取成功/失败”两个按钮明确标为设计演示，不模拟网络自动完成。
