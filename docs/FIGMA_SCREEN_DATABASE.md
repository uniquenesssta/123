## 3. 连接、保存与凭据

**连接并保存不是只读测试。** 当前路径建立候选连接后自动迁移、兼容检查、恢复中断任务并注册内置资料；取得健康后替换活动连接，再保存本机凭据。没有新增源码不存在的独立测试、手动初始化、备份、恢复或覆盖旧库按钮。

DB-A演示目标为`db-a.example.invalid:5432 / db_demo_a`，DB-B为`db-b.example.invalid:5432 / db_demo_b`。输入遮罩和技术脱敏地址都是合成示例，没有真实密码。编辑B时A仍为当前；B连接/迁移中的新延迟、容量和统计使用“—”，不能借用A结果。B成功也不复制A的统计。

已保存密码不回填，现有连接编辑页不凭空获得可提交的密码。最大连接数1–100、超时1–120秒为页面输入要求；非法或忙状态禁提交。字段原型只展示说明，不提供任意输入控制器。

本机保存失败后命令会断开服务；服务器上已完成的迁移不会撤销，也不能承诺恢复旧A。元数据和凭据先后写入，并非跨文件原子事务。结果未知先核验保存与活动连接，不自动重发密钥或连接请求。

清除连接只清理本机连接并断开服务，不删除服务器数据。清除失败可能涉及配置、凭据或断开中的不同阶段，必须分别核验。自动恢复失败不意味着服务器数据库不存在或没有数据。

## 5. 重置与不可恢复边界

重置以**已保存连接**为目标，不读取未保存的B表单草稿。名称确认按trim与`db_demo_a`比较；空、错误、匹配、目标已变化分别展示。目标变化拒绝旧确认。同名数据库可能位于不同服务器，运行时仍需绑定主机、端口、数据库及连接版本；不能把仅名称复核描述为完整身份保证。

清空涉及`ai_workspace`、`analytics`、`audit`、`catalog`、`feature`、`football`、`model`、`platform`、`research`、`review`十个应用schema，以及`public._sqlx_migrations`。`CASCADE`可能影响依赖这些对象的其他对象，不保证外部schema内所有依赖对象不受影响。

**schema删除事务先提交，再执行迁移。** 重建或重连失败不能写成“已回滚旧数据”。未知结果禁止自动破坏性重试。客户端没有备份/撤销/还原功能；只说明操作者需自行确认外部备份和恢复能力，不假称已有备份。

数据库本身和本机连接配置保留。成功后迁移、内置规则和系统资料会重新注册，因此不是所有表为0。重置成功是独立预置读回，不由最终确认制造真实成功；进入其他业务前须重新加载，旧批次、草稿和许可不能直接复用。
