## 3. 单页验收契约

每页首先读取对应源码语义、相关组件记录与最新画布，确认页面身份、功能入口、适用状态、编辑/只读边界和必要依赖。源CSS不提供视觉尺寸。

页面用现有Controls/Patterns的真实实例组合；新增依赖必须说明缺口，不把整个产品画面新建为组件来增加库计数。不detach，不导入整页截图伪装为可编辑设计。

状态按实际适用性覆盖默认、首次加载、保留数据刷新、空、错误、禁用、成功，以及有真实危险写操作时的确认。并非每一页都要伪造所有状态；不把loading、unknown、0、unconfigured与unhealthy混为一谈。

验证适用的Light/Dark、紧凑布局、文字换行、滚动区域、实例引用、变量绑定、对比度与控件目标。意图内的滚动溢出与非预期溢出分开记录；页面NAVIGATE/OVERLAY连接与继承的组件CHANGE_TO反应分别统计。截图须检查文字本身是否被裁切，不能仅凭外围bounds通过得出文字完整可见。

组件库、本页有限原型、跨路由联调、真实应用运行时测试为不同验收层。未接通的控件及后续运行逻辑必须明确记录；不得把预置定时器或状态跳转称为真实网络、权限、输入、持久化或端到端测试。

## 4. S01、S02已完成与后续回填

S01原验收为15个状态画面、47条页面/目录连接、134个Disabled控件无反应连接；完整历史证据见[S01记录](FIGMA_SCREEN_DASHBOARD.md)。S02完成后新增默认Light/Dark下两张快捷卡和两个“比赛”主导航入站连接，均指向真实S02画面。原记录“尚无跨页面连接”的描述属于该次历史状态，当前以本节和最新状态为准。

S02为33个产品状态、7个对话框、1个目录；最终339条NAVIGATE/OVERLAY连接与23项CLOSE动作，33状态和7对话框均可达。399个Disabled控件无反应连接。深层5,544个未隐藏嵌套实例可解析，非预期越界、失效引用、未绑定颜色和顶层重叠为0；19处明确纵向滚动单列。

S02保存失败保留双方22人的草稿；10+11名首发禁止提交；模型链路阻断不因保存成功而解除；导入冲突、格式错误和重复提交受控。高级设置与危险确认是设计示例，最终删除/归档写操作未接通真实或伪造的成功结果。全状态主题、折叠、滚动、表单持续性与运行时事务仍须后续验证。

原型清理移除了60条由克隆带入、错误指向旧S01主题/折叠画面的连接。当前S02只有明确“首页”控件可退出到S01，其他路由待真实目标完成后接入。
