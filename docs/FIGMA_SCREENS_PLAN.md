## 3. 单页验收契约

执行前读最新检查点、对应语义源码和直接依赖，再核对实际Figma节点。确认身份、入口、编辑/只读和危险操作边界；CSS不提供新视觉尺寸。

使用现有Controls/Patterns真实实例，确有缺口才补依赖。不detach、不新增整页主组件凑数、不用截图代替可编辑设计；共享API未变不重写其历史记录。

按业务需要覆盖默认、首次加载、保留旧数据刷新、空、错误、禁用、成功和必要确认。代表性预置不等于任意输入/所有对象控制器矩阵；不制造无意义组合、不声称未实现操作已完成。

unknown、loading、0、unconfigured与unhealthy分开。查看、预检、确认、写入、结算和能力回写分别校验；跳转不能授予权限或覆盖不可变证据。

检查代表性Light/Dark/Compact、换行、实例与SLOT深层结构、颜色变量、对比度和跳转身份。滚动与越界分列；截图核对残留默认文案。禁用控件须同时检查自身反应和可点击父容器旁路。

NAVIGATE/OVERLAY、CLOSE、其他动作分别计数，外部入站另计。视觉、限定原型、跨路由和运行时是不同层级；最终写入未接则明确说明，不连到假成功掩盖缺口。
