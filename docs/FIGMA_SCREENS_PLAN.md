## 3. 单页验收契约

执行前读取最新检查点、页面语义源码及直接依赖，再核对真实Figma节点。确认身份、入口、编辑/只读、异步与危险操作边界；CSS不提供新视觉几何。

只组合现有Controls/Patterns真实实例，确有缺口才补依赖。不detach、不创建重复Screen主组件凑数、不以截图替代可编辑设计；共享API未变不重写历史组件记录。

按实际需要覆盖默认、加载、保留旧数据刷新、空、错误、禁用、适用结果和确认。代表性预置不等于任意输入或全部对象控制器，不宣称未执行操作已经完成。

unknown、loading、0、unconfigured、unhealthy分开。查看、预检、写入、注册、绑定、执行、结算、验收、发布和消息保存分别判断；跳转不能授予权限或覆盖不可变证据。

检查Light/Dark/Compact、文本换行、实例与SLOT深层结构、绑定颜色、文字对比度、跳转身份、禁用控件自身和可点击父容器旁路。正常滚动与非预期越界分列；截图核对实际渲染。

NAVIGATE/OVERLAY、CLOSE、其他动作和外部入站分别计数。产品视觉、有限原型、完整跨路由和真实运行时分层验收。普通发送可以进入明确模拟等待，但不得把人工选择结果说成真实API响应；未执行最终写操作须明确。
