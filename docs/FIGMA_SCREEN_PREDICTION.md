## 4. 正式推演状态

完整节点清单见JSON。状态包括：未检查、检查中、阻断、仅影子、带警告、输入就绪、提供器不可用、窗口变更、无比赛、首次加载、加载失败、模型判定，以及条件性的运行中/结果/失败。

- Blocked：正式和影子均禁用。
- Shadow Only：只启用影子入口；影子提供器失败后，正式按钮仍禁用。
- Formal Ready / With Warnings：允许检查并尝试外部入口，但默认提供器未捆绑，原型转到入口不可用，而非直接产生结果。
- Context Changed：T-1h 改为 T-6h 后清空当前有效指纹，旧分数与许可失效。
- First Load / Load Error / No Matches 分开，不把未知当0，也不把读取失败当空数据。
- 条件结果画面明确假设已接入提供器：示例主胜46%、平局29%、客胜25%，仅用于界面验收。正常未接入入口不会直接进入该结果画面。
- 条件失败保留输入选择与审计，重试是手动预置跳转，没有自动重发。

通用P4按赛制匹配，P7作为外部模型选择保留在产品契约中。任意模型/规则组合、完整下拉选项和真实动态选值没有实现为全功能Figma应用，不声称完成全部P4/P7业务组合测试。
