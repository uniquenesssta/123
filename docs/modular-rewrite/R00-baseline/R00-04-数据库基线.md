## 2. 原始问题与本节点目标

- 原实现已有 SQLx 迁移器和 PostgreSQL 集成测试，但没有独立、可审计的 0001–0046 迁移指纹清单。
- 本节点建立迁移连续性、迁移内容、迁移运行入口、集成测试集合及关键不可变约束的静态基线。
- 本节点还提供专用测试库安全执行器，拒绝数据库名不含 `test` 的连接。
- 本节点不修改迁移 SQL、数据库结构、公共接口、数据格式或运行行为。
- 真实 PostgreSQL 迁移幂等和集成测试未在本节点执行；用户于 2026-08-04 明确要求将数据库实跑推迟到最终统一验证，并以 `main` 基线保留既有数据库接口。

## 10. 实施过程中的关键决策

| 决策 | 采用方案 | 未采用方案 | 原因 |
|---|---|---|---|
| 迁移内容身份 | 保存 GitHub 权威 Git blob SHA-1，并现场派生聚合 SHA-256 | 手工复制 SQL 后另算内容哈希 | 避免复制过程改变内容或换行 |

| 数据库实跑顺序 | 按用户当前明确要求延期到最终统一验证 | 阻塞全部后续 R0 节点 | 用户明确要求先继续 R0-05，且静态接口与迁移边界已经冻结 |
