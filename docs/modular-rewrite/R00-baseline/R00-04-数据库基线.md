## 8. 模块、接口与数据流变化

- 新增内容属于架构验证边界，不进入生产运行链路。

## 10. 实施过程中的关键决策

| 决策 | 采用方案 | 未采用方案 | 原因 |
|---|---|---|---|
| 迁移内容身份 | 保存 GitHub 权威 Git blob SHA-1，并现场派生聚合 SHA-256 | 手工复制 SQL 后另算内容哈希 | 避免复制过程改变内容或换行 |
| 跨平台文本 | 工作树统一按 LF 计算 Git blob | 直接哈希 Windows CRLF | 保持 Windows 与 CI 一致 |
| 新迁移处理 | 精确冻结 0001–0046，任何 0047 或旁路 SQL 都失败 | 允许自动吸收新迁移 | R0-04 要求无新迁移且基线不可静默漂移 |
| 数据库安全 | 数据库名称必须包含 `test` | 仅依赖用户确认 | 集成测试和重置测试具有破坏性 |
| GitHub Actions | 不修改工作流，不伪造 Actions 结果 | 临时修改 CI 或宣称已运行 | 当前工作流仅对 main push 或 PR 触发，new-A 无 PR；改工作流会扩大节点范围 |
| 节点状态 | 保持 VERIFYING | 在无数据库结果时标记 DONE | 专用测试库验收是硬门禁 |
