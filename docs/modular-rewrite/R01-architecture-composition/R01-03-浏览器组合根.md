## 2. 实际问题与目标

原 `src/main.ts` 同时承担浏览器入口、顶层失败处理、全局监听器注册、工作区状态关闭以及全部既有页面业务实现。R1-03 只迁移启动和生命周期组合职责，不拆分 Feature，不改变页面、路由、Tauri 命令或业务数据流。

## 3. 实际实现

- `src/bootstrap/main.ts` 成为 `index.html` 唯一模块入口。
- `createApplication.ts` 唯一解析 `#app` 根节点并创建 `ApplicationHandle`。
- `registerApplicationModules.ts` 只登记浏览器应用模块，不实现 Feature。
- `ApplicationHandle` 负责模块唯一注册、幂等启动、逆序销毁、启动失败回滚和复合错误保留。
- `src/main.ts` 不再自行启动；现有业务实现保留原位并通过 `createBrowserApplicationModule` 暴露 start/destroy 生命周期。
- document/window 全局监听器使用同一 `AbortController`，销毁时统一解除；OpenAI 示例解析定时器和 WorkspaceStateStore 保存/恢复生命周期同步关闭。
- 顶层启动失败由 `startApplication.ts` 统一渲染，既有用户提示语义和问题日志写入保持不变。
