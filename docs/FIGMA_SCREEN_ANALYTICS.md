## 4. 本页状态契约

### 历史、分析及后台任务

未读取、读取失败、成功空记录、刷新中和刷新失败分开。刷新保留上次数据，不重新显示为空或把旧结果当成本次成功。切换C1/T-1h到C2/T-24h后旧分区结论失效；新分区入口仅核对说明，不错用C1的运行确认。

任务的排队、运行、取消请求、取消终态、失败、完成和结果未知分别呈现。取消请求不表示已取消；失败/取消后仍须核对重试资格和尝试次数。结果未确认禁止自动重发。完成但有效样本为0时使用AN-DEMO-EMPTY，不解锁有效分析门槛。

Model Refreshing及Result Unknown明确保留上次AN-DEMO-A；完成读回的结果则标为当前示例，避免混用“上次”。任务进度、日期和统计均为预置数据，不是本次运行测量。表格仅显示代表性分组/分桶，不提供全量结果或承诺可由展示子集复算总指标。

### 质量、建议与能力审核

无scan_id不能因为critical=0显示已通过；扫描中不沿用通过结论。Q-DEMO-01是缺少正式赛果的严重问题，标记处理/忽略仅记录人工判断，不修复事实，也不自动授予H/I权限。

S-DEMO-01参数建议、S-DEMO-02能力建议、A-CAND-DEMO-01既有能力候选分别保留身份。接受能力建议只产生另一个pending能力候选；能力历史写入要单独审核。页面待审合计3项与H待判定证据队列属于不同口径；清除前者不等于后者已清零。

E-DEMO-01绑定MATCH-DEMO-01/T-1h，正确、部分正确、错误、无法验证四种判定分别打开确认，并有真实Text Field实例呈现必填判定说明的预置值。不把无法验证当作错误，不覆盖原始证据。

### 外部分析资料包

AP-DEMO-01、RESP-DEMO-01、当前数据库和AN-DEMO-A的身份分开核对。无包、待选文件、阻断、通过、文件改变、导入中和已导入待审分别呈现。文件或来源包变化使旧预检失效；导入中与已导入禁重复提交。导入只登记建议，不执行SQL、不改正式参数、不写能力历史。

真实模板生成、文件选择、再次读取校验、重复导入及结果不明恢复仍需运行时实现；当前确认均无执行连接。

### 参数生命周期

I-DEMO-01固定C1/PROFILE-DEMO-01/p4_league4.0.0/基线1.0.0/候选1.1.0/T-1h。接受仅进入影子队列；H阻断时影子按钮禁用，影子运行中不能重复执行。失败不能晋升；通过还需最新门禁、绑定未变和有效人工说明。

Binding Changed场景显示正式绑定已变为1.2.0，旧影子通过不能直接晋升1.1.0。晋升记录不覆盖历史运行，回滚使用DECISION-DEMO-01的原绑定快照；rolled_back/rejected/superseded只读，不重启旧操作。

候选定义、基线、影子结果与正式路由不是同一对象。各历史状态不是同一时刻的组合授权；有限导航不能证明任意竞态或数据库幂等。
