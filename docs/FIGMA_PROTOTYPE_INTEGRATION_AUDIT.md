## 3. 集成阻断项

### INT-01 · P1 · 默认导航仍有未接线和说明占位

34个默认明暗页面共有340个可见模块/页面导航实例，其中68个为当前选中项；剩余272个非选中入口中，176个到达对应模块/页面的真实产品目标，92个没有有效点击动作，4个仅打开说明弹窗。已接通的176个入口未发现目标模块/路由错误。

这里的92是两套主题中入口实例的数量，不是92条页面；这些统计仅覆盖默认34页，不外推为所有561状态的全部缺口。

### INT-04 · P2 · 全局返回/前进及折叠/重置仍是局部示例

34个Collapse控件中只有4个有画面跳转、28个没有动作、2个打开范围说明；4个跳转也只能证明固定布局示例存在。Reset workspace中8个禁用、18个没有动作、8个只打开说明。后续应明确哪些场景需要真正可演示、哪些仅留交付规格，不能声称完整状态持续性已经验收。

复验条件：代表性业务往返路径覆盖默认、详情、筛选和草稿，返回恢复约定状态；侧栏折叠仅改变布局，不改变对象或业务许可；需要放弃草稿时有明确策略。滚动位置、焦点、任意输入与多次前进/返回仍需动态交互和运行时验证。
